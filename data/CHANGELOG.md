# Changelog

All notable changes to the Data pack (`runax-data.excalidrawlib`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
All packs in the repository are released together.

## [Unreleased]

### Changed

- Neo4j is now the simple-icons mark (CC0) in Neo4j blue: the previous file came from a GPL-3.0 repository.
- DuckDB is now the icon from DuckDB's design manual, and MQTT and BullMQ use their official logos unmodified, instead of marks cut out of them.
- Captions follow vendor naming: at most two lines, small words lowercase.

### Added

- 34 icons: databases (PostgreSQL, MySQL, SQL Server, Oracle, SQLite, MongoDB, Redis, Valkey, Cassandra, CouchDB, Cosmos DB, ClickHouse, DuckDB, CockroachDB, Snowflake, Neo4j), messaging and streaming (Kafka, RabbitMQ, NATS, MQTT, ActiveMQ, BullMQ, Flink, Spark), search (Elasticsearch, OpenSearch, Kibana, Qdrant), lakehouse and pipelines (Iceberg, Airbyte, SeaTunnel, dbt, Airflow) and Firebase.
- The database and messaging logos moved here from the techno pack, with typos in their names fixed (Cosmos DB, Elasticsearch, PostgreSQL).
