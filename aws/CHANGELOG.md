# Changelog

All notable changes to the AWS Architecture Icons pack (`runax-aws.excalidrawlib`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
All packs in the repository are released together.

## [Unreleased]

### Changed

- Icons are drawn at AWS's predefined sizes: 64px services, 48px resources, 32px groups.
- Captions follow AWS's naming guidelines: at most two lines, "AWS" or "Amazon" never alone on a line, "and"/"for" lowercase.
- Two resource icons named like their service icon are captioned "Amazon EC2 Auto Scaling resource" and "AWS Management Console resource"; "Aternate" (a typo in AWS's file name) reads "Alternate".
- The README quotes AWS's terms and guidelines.

### Added

- 810 icons from the AWS Architecture Icons release of 2026-07-31: the largest size of each service, resource and category icon, unlabeled variants preferred.
- White-only `_Dark` variants are left out: they are invisible on a white canvas.
