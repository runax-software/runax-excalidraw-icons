## [0.1.0] - 2026-11-16

### Added

- 645 icons from the Azure Architecture Icons V25, captioned with their full service names ("Windows Admin Center"); icons Microsoft names alike carry its icon number ("Workspaces (00330)").
- The README quotes Microsoft's icon terms and guidelines.
- `runax-azure-native.excalidrawlib`: the icons drawn with Excalidraw shapes, which work in Excalidraw's library panel on their own (it drops a library's images on import) and take arrows like any shape.
