# Changelog

All notable changes to the Networking pack (`runax-networking.excalidrawlib`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
All packs in the repository are released together.

## [Unreleased]

### Changed

- Caddy and Calico are now their projects' own symbols (site icon, docs badge), instead of marks cut out of their logos.
- WireGuard is the full logo, unmodified, as its trademark policy requires; its license notes the required trademark acknowledgment.

### Added

- 35 icons: service meshes and proxies (Istio, Linkerd, Cilium, Envoy, Kuma, Consul, NGINX, Traefik, Kong, HAProxy, Caddy), ingress and gateways (Contour, Emissary-ingress, kgateway), CNI and cluster networking (CNI, Calico, Antrea, Kube-OVN, MetalLB, Kmesh, Submariner, Network Service Mesh, CoreDNS), identity (cert-manager, SPIFFE, SPIRE), VPNs (Tailscale, WireGuard, NetBird) and API protocols (gRPC, GraphQL, REST, OpenAPI, Swagger, Socket.IO).
- gRPC is its mascot Pancake: the CNCF's gRPC icon is the wordmark.
